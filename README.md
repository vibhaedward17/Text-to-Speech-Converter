Text to Speech

A simple desktop application that converts typed text into speech using Python's tkinter and pyttsx3 libraries.

Features


->Clean GUI built with Tkinter

->Instant text-to-speech conversion using pyttsx3

->Works completely offline — no internet required


Requirements


->Python 3.x

->pyttsx3


Install the dependency with:

-> pip install pyttsx3

Run the script:

-> python text_to_speech.py


Type any text in the input field and click Speak.
